CP : All in One

A Chrome extension for competitive programming: find contests, add calendar reminders, back up accepted solutions and keep question notes.

Three tabs: Contests, Calendar and Backups. Notes are available directly on supported question pages. Connections are optional; GitHub backups use one selected private repository.
