All In One CP privacy policy

Effective October 11, 2026. Applies to version 2.0.0. Maintained through our GitHub repository.

All In One CP shows programming contests, adds Google Calendar reminders, backs up accepted solutions to a selected GitHub repository, and saves local problem notes and review plans.

Information used

  • Contest schedule: The extension requests contest feeds from the configured backend. The hosting service can receive ordinary connection information such as IP address and request timing. No account credentials are included.
  • GitHub: After you authorize the GitHub App, access and refresh tokens are stored in local extension storage restricted to trusted extension contexts. Tokens are used directly with GitHub for sign-in renewal, permitted repository discovery and solution uploads. No app client secret is included in the extension. Choose one private repository; source is organized by platform and language. Notes/metadata uploads are off in this release.
  • Google Calendar: Chrome manages Google sign-in. The extension uses the calendar.events.owned scope to read and manage events on calendars you own, and normally writes to your primary calendar. It identifies extension-owned events to update or remove them; personal events are preserved. No calendar-list or calendar-creation scope is requested. Independent Add to Google Calendar links open Google for you to create an event manually; those events are not automatically managed or removed by the extension.
  • Programming sites: Accepted-solution capture on LeetCode, Codeforces, AtCoder, CodeChef and CSES reads relevant question/submission details, source and signed-in identity where needed to exclude other users' submissions. Browser-managed site sessions can be used for same-site source requests; passwords and cookies are not exported to our backend. CSES capture is limited to owned accepted result pages, not question-sheet import.
  • Notes: On supported questions on those sites plus HackerRank, GeeksforGeeks, SPOJ, Kattis and HackerEarth, the extension reads the question URL/title and notes you type. Notes, tags, bookmarks, review dates and solved flags stay on this device. They are not automatically synchronized between devices or sent to maintainers. Exported notes go to a file you choose.
  • Preferences: Non-secret preferences can use Chrome storage sync. Backup source, job history and notes use local storage/IndexedDB.

Removed profile sharing

Version 2.0 does not discover or collect public account profiles, ratings or solved counts for maintainers, and has no admin profile dashboard. Older installations with an optional sharing registration attempt authenticated withdrawal on upgrade and retry if the service is unavailable. The updated server rejects new profile registrations and retains only an authenticated withdrawal endpoint for old registrations. Historical registrations remain subject to the prior one-year retention limit until deletion succeeds.

Your controls

  • Connections are optional; Contests and Notes can be used without them. First-time setup can be deferred.
  • Disconnect GitHub or Google to remove local credentials and pause automatic actions. A request already in flight may finish. Revoke remote authorization in the provider's account settings.
  • Edit, export or delete local notes. Remove queued backup records to delete their stored source. Existing GitHub files require deletion on GitHub.
  • Remove extension-owned calendar events through Calendar. This pauses calendar synchronization.
  • Uninstalling removes extension-local data; downloaded exports, remote GitHub files and Google events remain until you remove them.

Security and third parties

Requests use HTTPS. GitHub App tokens and Chrome-managed Google credentials are not sent to our contest backend. Permissions are limited to supported platform sites and required provider endpoints. The extension does not include advertising, sell personal information or collect cross-site browsing history. GitHub, Google, programming platforms and hosting providers process requests under their own policies.

Contact and changes

For questions or deletion concerns, contact the maintainer through the repository issues. This policy will be updated when the extension's data practices change.
